- **The web app gets pages for data sources, with the feature on.** A Data
  section searches and browses what the person may read and opens items with
  their files. Integrations lists sources with their runs, parity result and
  publish control. Admin gains Data access for scopes, grants, identity links
  and redaction sets, and Profile lists a person's linked and connected
  accounts ([Data sources](docs/data-sources.md)).
