# What an MMM dashboard shows — client-validated checklist

Distilled from delivered client dashboard reviews and feedback. Use these views
unless the client asks otherwise; drill-down order is **overview → channel deep
dive → model inventory**.

1. **Executive summary landing tab** — a top-level narrative first: "media drove
   $X.XM incremental revenue this quarter; top performer: <channel>; biggest
   opportunity: <channel> at NN% saturation." Key numbers as cards WITH 90%
   credible intervals. Where lift was / was not measured belongs here too, with
   drill-down (client-requested, 2026-09).
2. **Contribution waterfall with credible intervals** — CIs so small
   quarter-over-quarter shifts read as within-uncertainty, not as news.
3. **Spend share vs effect share, side by side, PLUS the efficiency read** —
   showing the two columns is not enough; add the reallocation insight they
   imply (which channels are over/under-invested). This was the #1 gap flagged
   in client review.
4. **ROI and CPIK per channel with 90% CIs** — "exactly right" per review.
   Marginal ROI alongside average ROI: close to average = room to grow; well
   below = diminishing returns.
5. **Response curves / saturation position** — where each channel sits on its
   curve right now.
6. **Baseline decomposed, min/max-rebalanced** — subtract each baseline
   component's weekly minimum into a hidden "always-on" bucket so the variable
   drivers plot at a readable scale; totals preserved, media bars untouched.
7. **Budget reallocation view** — current vs optimized allocation and the
   expected lift, stated with uncertainty.

Rules: original units everywhere (shares and ROAS never in scaled space);
uncertainty on anything a decision hangs on; narrative before numbers.
